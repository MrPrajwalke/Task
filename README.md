README

This folder has 3 simple files.

1. Register.java
   - This is a Java program.
   - It asks for a name, email, and password.
   - It saves the user in memory.
   - If the email is already used, it shows an error.

2. Login.java
   - This is a Java program.
   - It asks for an email and password.
   - It checks if they match a saved user.
   - It has one test user already saved: test@example.com / 1234

3. index.html
   - This is a simple web page.
   - It shows a welcome message.
   - It has two buttons: Register and Login.

How to run the Java files:
   1. Open a terminal in this folder.
   2. Type: javac Register.java
   3. Type: java Register
   4. Do the same steps for Login.java

How to open the HTML file:
   1. Double-click index.html
   2. It will open in your web browser.

Note: The Java files and the HTML file are not connected yet.
The Java files run in the terminal.
The HTML file only runs in the browser.
